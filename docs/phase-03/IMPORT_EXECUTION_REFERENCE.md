## آلية العمل الحالية

1. الواجهة ترفع الأصل مرة واحدة. الـAPI يتحقق من الملف ويحفظ نسخة خاصة وبصمتها وينشئ التشغيل والمهمة.
2. `ProcessImportWorkbook` يشغل `ImportWorkbookProcessor`.
3. `ImportWorkbookReader` يفحص العناوين. `XlsxRowStream` يقرأ قيم XLSX في مرور XML واحد. XLS وCSV لهما قارئاهما الحاليان.
4. `ImportIngestionService` يطبق خريطة الأعمدة والتحويلات، يحفظ صفوف المصدر، يحل هويات الشحنات والتجار والمراكز، ويكتب جداول التفاصيل والتحذيرات في معاملات.

6. `ImportPublicationService` يتحقق من الاكتمال وينشر المراجعة ويحدث مؤشر الملف النشط.
7. الواجهة تستعلم عن الحالة ثم تجمع صفحات الشحنات، كل صفحة حتى 1,000 صف، قبل عرض التحليلات. يجب قياس هذا الجزء أيضًا.
